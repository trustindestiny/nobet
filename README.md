# Nöbet Asistanı · Kasım 2026

Mobil uyumlu, çevrimdışı çalışabilen PWA nöbet listesi.

## Özellikler
- Günlük nöbet ekranı ve hafta sonu ek görev tablosu
- Kasım içinde bugünün tarihini otomatik seçme; gün değişiminde yenileme
- Personel adıyla arama ve eşleşen satırları filtreleme
- Haftanın günlerine göre nöbet/icap ve boş hafta sonu özeti
- Tablo hücrelerini düzenleme ve tarayıcıda yerel saklama
- Service worker ile daha önce açıldıktan sonra çevrimdışı kullanım
- Android/Chrome yükleme istemi ve iPhone/iPad Ana Ekrana Ekle yönergesi

## GitHub Pages
Depo ayarlarında **Settings → Pages → Build and deployment → Source → GitHub Actions** seçin. `main` dalına her gönderimden sonra site otomatik yayınlanır.

Site adresi: https://trustindestiny.github.io/nobet/

## Telefona yükleme
- Android: Siteyi Chrome'da açıp **Uygulamayı yükle** düğmesine dokunun (veya Chrome menüsünden yükleyin).
- iPhone/iPad: Siteyi Safari'de açın → Paylaş → Ana Ekrana Ekle.
